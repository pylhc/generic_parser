## Setup coverage badge

Below are examples of the badges you can use in your main branch `README` file.

### [Shields.io](https://shields.io) Json Endpoint

[![Coverage badge](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/pylhc/generic_parser/python-coverage-comment-action-data/endpoint.json)](https://htmlpreview.github.io/?https://github.com/pylhc/generic_parser/blob/python-coverage-comment-action-data/htmlcov/index.html)
